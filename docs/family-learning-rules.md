# 家庭学习试卷制作与校验规则（2026-11-06）
适用于高语桐、高语牧的语文、科学及今后的其他学科练习网页。

## 年级按学年自动递增
- 2026秋—2027夏：高语桐六年级；高语牧四年级。
- 2027秋—2028夏：高语桐初一；高语牧五年级。
- 2028秋—2029夏：高语桐初二；高语牧六年级。
- 按每年秋季新学年升一级；不在1月1日自动升年级；保留原学期历史试卷。

## 出题范围与字词真实性
1. 以用户提供的教材照片、可核对的表和上传 JSON 为出题依据，原书主表全部生字词都要录入，不得因黑斜线、圈选、蓝色底纹而排除。
2. 逐课逐字核对目标字，严禁把形近字错录成另一个字。例如六年级原图：暮（不是蓑）、辆（不是捆）、第6课嗓（不是嚷）、惨（不是修），参差读 cēn cī。
3. 识字表、写字表、词语表用途分开；写字表才是必写字来源，教材词语表提供完整词语练习。额外组词仅作为“补充示例语境”，必须醒目标注，不冒充原书词语或新增必写字。
4. 原书已标注的同音字、形近字、多音字、易错字优先作为专项；不得把尚未转录的旁注称为“已经完整收录”。未经核对的 OCR 信息必须标注“待校对”，不凭推测把它修成另一项。
5. 自动生成的拼音应有准确词语语境；多音字必须按词组读音核对，无法确认时明确标注“待校对”，不能伪称教材原音。

## 练习交互
1. 题目要有足够的拼音及词语/生活情境提示；不能出现“第几课·□”这样缺少判别信息的题目。
2. 拼音默写采用缺字词语，所有重复出现的目标字均要遮盖，不能从旁边看见答案；易混字题给出词语的拼音、缺字形式以及选项；应用题提供具体情境。
3. 答题页、页脚、题库区域不能提前显示完整答案表或词语清单。孩子完成当前轮所有应作答题目后，才能启用“批改并显示答案”，随后才显示正确答案和错题。
4. 批改状态按试卷/题型/分组/轮次独立保存，切换轮次后返回要还原已显示答案及成绩；标记完成不能替代批改、不能提前放出答案。
5. 每题三轮复习记录，预习、复习、期末复习分开统计，错字榜累计且保留最近表现；历史记录不得被新版本覆盖。

## 每题三次纸笔核对（2026-11-06 确认的强制规则）
1. **每一道字词题的下方，始终同时显示三个明确的可见勾选框**：「第1次写对」「第2次写对」「第3次写对」。未完成核对的框可以暂时禁用，但不得隐藏或仅渲染当前次数，也不得用一个「第1轮」勾选框代替三格。
2. **“题目分组”与“复习次数”严格分离**：例如六年级180字分成五组，每组36字；这是五组题目，不是一个字的五次复习。每组内每个字均有独立的第1、第2、第3次核对记录。四年级字词分组同理。
3. 勾选的语义是“这一题在本次**纸上独立手写正确**”，不是“做完”“看过答案”或“自动批改过”。正确才勾选；错误/未掌握不勾选；未作答或未核对的一次不能提前勾选。
4. 先独立完成本次纸笔练习，再操作「纸上已写完／显示参考答案」，核对后允许为对应次数逐题勾选、取消勾选和更正；已经完成的一次重新打开后仍应能够查看并更正，不允许“完成”锁死勾选。
5. 勾选状态按**孩子、科目、学期、学习阶段、题库版本、题目分组、具体题目、练习次数**分别存储。切换组别、次数、重新打开或在同浏览器刷新时，已完成的勾选记录要恢复，不能把前一次的勾选自动继承成第二/第三次。
6. 同一个字在不同组、不同复习次数的记录必须可追溯；保存完成的次数与错字榜应能区分三次，不可仅用“本轮共几题”代替逐字历史。未勾选题记为待巩固，但只有完成核对并提交的练习才写入正式成绩。
7. 纸笔手工核对和网页输入自动批改是两种独立路径：前者人工判断字形是否写对；后者只有输入完整后才自动批改。两者不得互相覆盖答案、草稿、成绩；修订云端已同步成绩要保留历史并生成明确的较新修订记录。
8. **参考答案必须按本次访问重新授权显示**：即使以前某次已经核对、网页刷新、返回相同分组/次数、跨设备恢复旧成绩，默认仍隐藏答案；`revealed` 等历史核对标记只代表已经核对过，不代表现在允许展示。只有本次明确点击「核对并显示参考答案」且确认后才显示；三次勾选状态和历史成绩不能清空，也不能借切换轮次自动露出答案。
9. **验收必须检查已发布的真实网页，不得只看仓库代码或只凭 Github Actions 正在运行就宣称上线。** 特别验证每张题卡有三格，第一轮核对后能勾第1次，另两格可见且未开放，第二次核对后独立勾第2次，切换/刷新恢复，旧版链接与缓存更新后仍正确。部署未成功则明确说明，而非声称可用。

## 云端与发布
1. 每张试卷使用唯一 quiz_id 和学期信息，连接家庭现有 Supabase；保留 family_access 的授权限制和 Edge Function 暗号解锁，Service Role Key 永不放入 HTML。
2. 草稿先本机保存；已批改且完整的轮次才能写入 quiz_attempts_secure 和 quiz_item_results_secure；严禁用假成绩验证。
3. 若独立语文仓库未开启 GitHub Pages，可在已启用 Pages 的学习站点发布镜像，并把两处源代码保持同步。
4. 发布前至少验证：表数及字词数量、源图对照、UI 不泄露答案、未完成无法批改、切换轮次回显、云端连接与恢复代码、GitHub Pages 部署结果。
